# Бронирование номеров гостиницы

Вариант 10. Исходная модель: 7 справочников, 3 перечисления, 3 документа, отчет. Тестовые данные синтетические. Порог сообщения: 30 000 руб.

Статус: исходная разработка, нативная приемка еще не выполнена. Модули пересчитывают документы при записи; интерактивный пересчет и формы еще требуют проверки. Запрос отчета выбирает брони по дате заезда, начисления услуг и оплаты по состоянию на конец периода. Не использовать как подтверждение готовности DT.
